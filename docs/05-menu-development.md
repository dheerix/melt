## Purpose

Develop a compact menu with repeatable quality and room for seasonal creativity.

## Current decisions

- Keep exact recipes, trials, supplier data, and ingredient costs outside Git.
- Test flavour, structure, holding, transport, portioning, and presentation before launch.

## Open questions

- What core flavour set balances choice and consistency?
- Which seasonal ideas deserve limited release?

## Action items

- Use coded test records in private storage.
- Complete an allergen and production review for every menu change.

## Metrics

Track test pass rate, remakes, prep time, ingredient overlap, and customer response privately.
