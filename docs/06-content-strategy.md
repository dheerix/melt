**Last reviewed:** 2026-08-02

## Purpose

Turn product craft into clear, useful content that earns local trust and enquiries.

## Current decisions

- Prioritize finished bakes, process details, ordering education, founder voice, and celebration stories with permission.
- Never imply guaranteed availability or publish customer-identifying details.

## Open questions

- Which formats consistently generate qualified enquiries?
- What posting rhythm is sustainable during production weeks?

## Action items

- Build a rolling four-week content board.
- Secure explicit consent before sharing customer-related material.

## Metrics

Track saves, shares, completion, profile actions, enquiries, and content-assisted orders.
