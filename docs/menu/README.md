# MELT Menu Workspace

This folder contains the evolving product/category write-ups, menu drafts and category-specific creative direction.

## Structure

- `everyday-melt/` — Everyday / dry cakes
- `celebration-cakes/` — classic, Desi and seasonal celebration cakes
- `bento/` — Bento as a full product category
- `cheesecakes-desserts/` — cheesecakes and plated/boxed desserts
- `chocolates/` — handmade chocolates and gifting

The master cross-category decisions live in [MELT Master](../04a-melt-master.md).

Each category should eventually contain:
- `README.md` — concept and product write-up
- `menu.md` — customer-facing menu copy
- `assets/` — category-specific working assets/references

Exact recipes, costs, suppliers and sensitive operational data do not belong in public Git.
